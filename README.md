# **Онлайн-магазин спортивной экипировки «SUPER SHOP»**

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Фронтенд включает в себя интуитивно понятный интерфейс. Перемещение между категориями товаров производится в шапке страницы. В каждой категории предусмотрен механизм пагинации. О количестве предоставленных к обзору товаров на странице из общего списка сигнализирует статус фильтрации.
<video src="https://github.com/user-attachments/assets/39bb07e1-73ab-4e37-bf48-52595201a9e9" width="600" controls></video>

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Переход в карточку продукта для его подробного анализа осуществляется кликом по превью товара. На открывшейся странице можно ознакомиться с характеристикой продукта, его ценой (с учетом скидки и без) и фотогалереей. Также для ознакомления система подтягивает сюда превью похожих товаров. Вернуться к предварительному просмотру ассортимента можно по ссылке "Вернуться в каталог" либо через меню.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;[Демонстрация работы с карточкой продукта](Видео/2.mp4)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Прежде чем добавить товар в корзину, необходимо войти в личный кабинет. Если у пользователя он уже создан, то необходимо авторизоваться по кнопке "Вход", новым пользователям - пройти регистрацию по одноименной кнопке. После входа пользователь автоматически оказывается в личном кабинете, где впоследствии должен оставить данные, необходимые для оформления заказа. В правой части страницы будут отображаться статусы его заказов. В случае необходимости смены пароля, есть возможность воспользоваться соответствующей опцией.
<video src="https://github.com/user-attachments/assets/c9eb932b-f2ea-40fc-954f-603b46f116bb" width="600" controls></video>

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Отправляется товар в корзину по соответствующей кнопке в карточке товара. При открытии корзины по выбранному товару подтягивается вся необходимая информация. Есть возможность установки количества товара и его удаления из списка покупки. Итоговая сумма (общая и в разрезе товара) подсчитывается автоматически и размещается в конце страницы и отдельным блоком (вместе с количеством) под меню для информативной цели. Продолжить покупки можно по ссылке "Вернуться к покупкам" либо так же через меню.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;[Демонстрация работы с корзиной](Видео/4.mp4)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Оформление заказа производится в 3 шага: сверка контактной информации и информации о доставке, а также выполнение подтверждения заказа. Данные в эти формы равноценны тем, что были указаны в личном кабинете, но при желании их можно изменить. После подтверждения заказа пользователь информируется об успешном оформлении заказа и присвоении ему уникального номера.
