# **Онлайн-магазин спортивной экипировки «SUPER SHOP»**

&nbsp;&nbsp;&nbsp;&nbsp;Фронтенд включает в себя интуитивно понятный интерфейс. Перемещение между категориями товаров производится в шапке страницы. В каждой категории предусмотрен механизм пагинации. О количестве предоставленных к обзору товаров на странице из общего списка сигнализирует статус фильтрации.

&nbsp;&nbsp;&nbsp;&nbsp;Переход в карточку продукта для его подробного анализа осуществляется кликом по превью товара. На открывшейся странице можно ознакомиться с характеристикой продукта, его ценой (с учетом скидки и без) и фотогалереей. Также для ознакомления система подтягивает сюда превью похожих товаров.
Вернуться к предварительному просмотру ассортимента можно по ссылке "Вернуться в каталог" либо через меню.
Видео 2

&nbsp;&nbsp;&nbsp;&nbsp;Прежде чем добавить товар в корзину, необходимо войти в личный кабинет. Если у пользователя он уже создан, то необходимо авторизоваться по кнопке "Вход", новым пользователям - пройти регистрацию по одноименной кнопке. После входа пользователь автоматически оказывается в личном кабинете, где впоследствии должен оставить данные, необходимые для оформления заказа. В правой части страницы будут отображаться статусы его заказов. В случае необходимости смены пароля, есть возможность воспользоваться соответствующей опцией.
Видео 3
&nbsp;&nbsp;&nbsp;&nbsp;Отправляется товар в корзину по соответствующей кнопке в карточке товара. При открытии корзины по выбранному товару подтягивается вся необходимая информация. Есть возможность установки количества товара и его удаления из списка покупки. Итоговая сумма (общая и в разрезе товара) подсчитывается автоматически и размещается в конце страницы и отдельным блоком (вместе с количеством) под меню для информативной цели.
Продолжить покупки можно по ссылке "Вернуться к покупкам" либо так же через меню.
Видео 4

&nbsp;&nbsp;&nbsp;&nbsp;Оформление заказа производится в 3 шага: сверка контактной информации и информации о доставке, а также выполнение подтверждения заказа. Данные в эти формы равноценны тем, что были указаны в личном кабинете, но при желании их можно изменить. 
После подтверждения заказа пользователь информируется об успешном оформлении заказа и присвоении ему уникального номера.
Видео 5

&nbsp;&nbsp;&nbsp;&nbsp;Управление бэкендом реализуется с помощью кастомного веб-интерфейса. В распоряжении администратора:
-просмотр информации по созданным заказам, присвоение им статусов, изменение состава заказа и его полной отмены
Видео 6
-просмотр и удаление пользователей онлайн-магазина
Видео 7
-добавление/ удаление категорий товаров в базу данных/из базы данных, их просмотр и переименование, 
Видео 8
-добавление/удаление товаров категории в базу данных/из базы данных, их просмотр с возможностью редактирования конкретных реквизитов
